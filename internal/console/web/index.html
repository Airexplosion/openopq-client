当前账号独立配置。HTTP / 正向 WS 的启停和端口在「协议入口」设置；这里配置事件上报与反向连接。

HTTP 事件上报

POST JSON，包含 X-Self-ID；设置 Secret 后使用 HMAC-SHA1 签名，支持响应中的快速操作。不自动重发，避免重复操作。

反向 WebSocket

由 OpenOPQ 主动连接机器人框架，携带 X-Self-ID / X-Client-Role，支持 Token 鉴权和断线重连。删除一行并应用即可停用。
