# 账号、扫码与会话切换

在“账号与状态”选择或添加 QQ 号，点击“获取登录二维码”，用相应账号扫码。上线后记住两种标识：QQ 号是对外业务身份，会话 ID 用于本次进程中的账号专属入口。

## 验证两个账号相互独立

1. 切到账号 A，从 API 调试台复制它的外部 OneBot 11 HTTP 地址，调用 `get_login_info`。
2. 切到账号 B，重复一次。两次响应的 `data.user_id` 应分别对应 A 和 B。
3. 将这两个地址填进各自的机器人配置。发送动作里的 `user_id` 或 `group_id` 表示接收方，不会替你选择发送账号。

切换页面中的当前账号不会注销另一个账号。需要停止某个账号时，在“账号与状态”核对 QQ 号后点“断开当前会话”。下次启动恢复失败，先核对数据目录，再决定是否重新扫码。
