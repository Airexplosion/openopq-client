# 控制台导览

浏览器打开启动日志中的本机地址，用控制台密钥解锁。进入后先看当前选中账号，右侧显示的是这个会话的数据。

| 面板 | 适合回答的问题 |
| --- | --- |
| 运行概览 | 哪个账号在运行？签名服务是否可达？网关收到事件了吗？ |
| 账号与状态 | 二维码是否过期？当前选中哪个 QQ？设备身份是否沿用？ |
| 网关设置 | 机器人应该连哪个端口、用哪个协议和令牌？ |
| API 调试台 | 发给当前账号的动作返回了什么？ |
| 实时日志 | 问题发生前后，当前会话记录了什么？ |
| 运行诊断 | 哪些状态可以导出给维护者排查？ |

网关 WebSocket 数量只统计通过本网关的连接；HTTP 是无状态请求，看活动数和累计数。只有 HTTP 客户端时，WebSocket 数为零也可能一切正常。

## 聊天状态指令

在群聊或私聊单独发送 `#oop`，客户端会回复版本、运行平台和运行时长。用登录客户端的 QQ 发送 `#oop off` 关闭回复，或发送 `#oop on` 恢复。也可以在 WebUI 的「网关与会话设置」里切换。默认开启，每个账号独立保存。
