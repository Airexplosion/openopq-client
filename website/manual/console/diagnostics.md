# API 调试台与日志诊断

**先做只读调用。** 在“API 调试台”选择目标账号，试一次 `get_login_info` 或 v12 的 `get_version`。记下请求入口、响应时间和响应正文。控制台内置测试入口与外部客户端地址分别显示：内置测试通过后，再用机器人自己的令牌访问外部地址。

## 用时间和账号对齐日志

切到“实时日志”，选定出现问题的会话，按级别过滤。快速刷屏时关掉自动滚动，定位请求附近的记录。会话缓冲最多保留 700 条；需要留存时及时导出，或启动时指定 `--log-file`。

## 给维护者一份能用的反馈

在“运行诊断”导出脱敏快照，同时说明客户端版本、发生时间、协议、动作及预期结果。截图或手工复制的命令也要单独检查，尤其是签名 URL、Bearer 头和二维码。遇到连接问题可按[现象表](../ops/troubleshooting.md)逐项定位。
