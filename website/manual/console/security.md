# 管理密钥与协议令牌

三种凭据解决不同的问题。排查 401 时，先看请求发往哪里。

| 凭据 | 使用者 | 在哪里使用 |
| --- | --- | --- |
| 控制台密钥 | 操作网页的管理员 | 本机控制台解锁；初始密钥文件路径在启动日志中 |
| HTTP Token | 调用机器人动作的程序 | 外部 HTTP 请求的 Authorization: Bearer 请求头 |
| WebSocket Token | 建立网关连接的程序 | 外部 WebSocket 握手请求 |

进入“网关设置 → 安全”检查对应开关。控制台复制出的外部地址不包含令牌；脚本从环境变量读取它，在请求头中传递。轮换凭据后更新机器人端配置并重新连接。回调到其他服务时，另按对应上报或反向 WS 配置填写目标要求的凭据。

本机控制台入口是 `127.0.0.1`。机器人在另一台机器上时，它的 `127.0.0.1` 指向它自己。需要跨机器部署时，用受控隧道或受保护的代理连接到网关，避免把管理界面直接暴露给公网。
