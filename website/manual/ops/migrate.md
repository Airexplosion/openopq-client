# 备份、换机与恢复

**最可靠的备份单位是正在使用的 Config.json 和整个数据目录。** 如果启动时指定过 `--data-dir`，备份那个目录；默认目录是工作目录下的 `data/`。

| 内容 | 用途 |
| --- | --- |
| `devices/` | 各账号持久化的设备档案 |
| `qq-logins/` | 登录状态及用于读取加密记录的本地密钥 |
| `transports/` | 各会话的网关传输设置 |
| `signer-sessions/` | 客户端与兼容签名服务恢复会话时使用的本地状态 |

停止旧实例后再复制。把目录和配置放到新机器，让新进程以有权读取这些文件的账号运行。先查看“账号与状态”，再用该账号的协议入口验证一次。

如果设备档案丢失，新设备可能遇到签名服务返回 HTTP 409。先确认旧实例已经停止。支持两分钟换机接手的服务需要等待旧设备停止活动满两分钟；其他服务的恢复策略以提供方为准。反复重建账号会继续产生新设备身份。
