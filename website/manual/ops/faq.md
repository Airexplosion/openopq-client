# 常见问题

### 为什么安装后还要填签名地址？

下载包提供 QQ 客户端和本地网关。客户端建会话时会请求你配置的外部签名服务；地址和支持的 QQ 版本由服务方提供。详见[签名与基础配置](../config/base.md)。

### 我只想用 OneBot 12，为什么开了 both 却连不上？

模板里的 `both` 表示 OPQ 和 OneBot 11。把 `Protocol` 改为 `onebot12` 或 `all`，重启后在当前账号的“网关设置”检查 v12 HTTP/WS。

### 退出网页以后，机器人还能在线吗？

“锁定并退出控制台”结束网页管理会话；QQ 进程仍可处理消息。“断开当前会话”才会主动断开选中账号。停止客户端进程则会影响它管理的账号。

### 为什么机器人拿到图片路径，自己却找不到文件？

v11 扩展 `get_file` 返回网关机器上的缓存路径。客户端与机器人在不同机器或容器时，只有网关一侧天然能读到它。群文件下载地址走[群文件接口](../api/groups.md)。
