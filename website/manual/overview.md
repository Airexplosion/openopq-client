# OpenOPQ 使用手册

OpenOPQ Client 在本机维持 QQ 会话，把消息交给机器人程序。先用控制台让一个账号上线，再把控制台给出的协议地址填到机器人框架里。阅读手册时，可以从你手头的问题进入。

| 我现在要做什么 | 从这里开始 | 怎么知道做对了 |
| --- | --- | --- |
| 第一次登录 | [选择安装包](install.md) · [扫码并验证](start.md) | 查询登录信息得到自己的 QQ 号 |
| 同时运行两个机器人 | [账号与会话](console/accounts.md) | 两个账号专属入口返回不同的账号 |
| 让机器人收到消息 | [协议与事件传输](config/transports.md) | 收到目标账号的一条群消息事件 |
| 更换机器 | [备份与迁移](ops/migrate.md) | 新机器沿用原设备档案，上线后能收事件 |
| 编写接入程序 | [开发者导读](dev/architecture.md) · [动作索引](api/actions.md) | 能区分动作响应与异步事件 |
| 突然连不上 | [按现象排查](ops/troubleshooting.md) | 定位到签名服务、QQ 登录或机器人连接中的一层 |
