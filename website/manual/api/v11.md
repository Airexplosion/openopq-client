# OneBot 11

OneBot 11 把机器人操作称为 **动作**，把收到的消息、通知和申请称为 **事件**。例如，收到一条群消息时先从事件读出 `group_id` 和 `message_id`，再调用 `send_group_msg` 回复。

## 地址和响应

| 用途 | 入口 | 说明 |
| --- | --- | --- |
| 调用动作 | `POST /onebot/v11/<动作名>` | JSON 正文直接放参数 |
| 收事件并调用动作 | `ws://127.0.0.1:8087/onebot/v11/ws` | WebSocket 上发送 action、params，可带 echo 对应响应 |
| 仅接收事件 | `/onebot/v11/event` | 正向 WebSocket |
| 列出当前能力 | `GET /onebot/v11/get_supported_actions` | 以当前运行实例的返回为准 |

启用鉴权时，HTTP 与 WebSocket 握手分别使用对应的 Bearer 令牌。多个账号共用端口时，将控制台给出的 `/accounts/<session>` 放在路径前。

```json
{"status":"ok","retcode":0,"data":{"user_id":10001,"nickname":"示例机器人"}}
```

先检查 HTTP 状态，再检查 `retcode`。HTTP 401 检查访问令牌；HTTP 200 也可能是业务错误，此时查看 `wording`。

## 账号、群和消息

| 动作 | 要传什么 | 返回什么 |
| --- | --- | --- |
| `get_login_info` | 无 | 当前账号的 user_id 和 nickname |
| `get_friend_list` | 无 | 好友资料列表 |
| `get_group_list` | 无 | 群列表，包括 group_id、group_name |
| `get_group_member_list` | group_id | 目标群的成员资料 |
| `send_private_msg` | user_id、message | 新发消息的 message_id |
| `send_group_msg` | group_id、message | 新发消息的 message_id |
| `get_msg` | message_id | 当前账号缓存的原消息及发送者 |
| `get_forward_msg` | id（forward 段中的 data.id） | messages，转发里的消息列表 |
| `delete_msg` | message_id | 请求撤回消息；以 retcode 判断结果 |

```json
{"action":"send_group_msg","params":{"group_id":123456,"message":[{"type":"reply","data":{"id":"456"}},{"type":"text","data":{"text":"收到"}}]},"echo":"reply-1"}
```

上例是 WebSocket 消息；用 HTTP 发到 `/onebot/v11/send_group_msg` 时，正文只取 `params` 对象。引用 ID 来自当前账号在同一会话收到的消息。

## 媒体与群文件

| 动作 | 要传什么 | 返回什么 |
| --- | --- | --- |
| `get_file` / `get_video` | 当前账号观察到的 file 或 file_id | file 是网关磁盘路径，另有 filename、size；远程机器人不能直接读取该路径 |
| `get_image` | 图片段 file | 图片元信息 |
| `get_record` | 语音段 file，可选 out_format | 原始元信息；指定支持的格式时含转换后的 base64 |
| `get_group_root_files` | group_id | 群根目录 files 和 folders |
| `get_group_files_by_folder` | group_id、folder_id | 子目录中的文件和文件夹 |
| `get_group_file_url` | group_id、列表给出的 file_id 和 busid | url，可用于下载该群文件 |
| `get_group_file_system_info` | group_id | 文件数量、数量上限、已用空间和总空间 |

`get_file` 里的媒体标识来自聊天事件；群文件的 `file_id` 和 `busid` 来自群目录列表。参见[可运行的文件与语音示例](../examples.md)。

## 事件怎么读

群消息常用字段有 `self_id`（接收账号）、`group_id`（所在群）、`user_id`（发送人）、`message_id`（引用目标）和 `message`（有序消息段）。好友或群申请的 `post_type` 是 `request`，处理申请时用原事件的 `flag`。HTTP 上报或反向 WebSocket 可在账号的协议设置中配置。
