# OneBot 12

启用 `Protocol: all` 或 `onebot12` 后，所有 HTTP 动作都发往 `POST /onebot/v12/`。请求类型为 `application/json`。同一路径支持正向 WebSocket，可以在一条连接上接收事件和动作响应。

```json
{"action":"get_self_info","params":{},"self":{"platform":"qq","user_id":"10001"},"echo":"self-1"}
```

`action` 是动作名，`params` 是参数对象。多账号用 `self` 指定执行账号，QQ 号、群号和消息 ID 用字符串。可选字符串 `echo` 用于把返回结果和请求对应起来。响应包含 `status`、`retcode`、`data`、`message`。HTTP 415 表示正文类型不对；业务错误查看 retcode 和 message。

| 动作 | 参数与用途 | 结果 |
| --- | --- | --- |
| `get_version` | 空对象，查询实现信息 | 实现名和版本信息 |
| `get_supported_actions` | 空对象，查询当前传输支持哪些动作 | 动作名数组 |
| `get_status` | 空对象，查看连接情况 | 状态和机器人账号信息 |
| `get_self_info` | 空对象，查询选中的账号 | 用户 ID 和名称等资料 |
| `get_friend_list` / `get_group_list` | 空对象 | 好友或群资料数组 |
| `get_group_member_list` | group_id | 指定群的成员列表 |
| `send_message` | detail_type、user_id 或 group_id、message | 已发送消息的 message_id |
| `delete_message` | message_id | 撤回指定消息 |
| `get_latest_events` | HTTP 轮询，按需使用 limit、timeout | 缓冲中的事件列表 |

群消息请求示例：

```json
{"action":"send_message","params":{"detail_type":"group","group_id":"123456","message":[{"type":"text","data":{"text":"你好"}}]},"echo":"group-1"}
```

正向 WebSocket 连接后先收到连接元事件。使用反向 WebSocket 时子协议为 `12.openopq`。HTTP 和 WS 令牌可分别设置，控制台密钥用于登录控制台。
