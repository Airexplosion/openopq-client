## 下载

Windows x64 选 `windows-amd64.zip`；Apple 芯片的 Mac 选 `darwin-arm64`，Intel Mac 选 `darwin-amd64`；Linux 按处理器选择 `linux-amd64` 或 `linux-arm64`。使用 `SHA256SUMS.txt` 核对压缩包。

升级前请停止旧客户端，保留自己的 `Config.json` 和 `data/`。登录需要兼容的外部签名服务。换机接手规则由签名服务端提供。
